# 💸 Split Money Friends

Split Money Friends is a simple React application for managing shared expenses with friends. It allows users to add friends, split bills, and automatically track who owes money to whom.

## ✨ Features

- Add new friends
- Split bills between friends
- Track balances
- Display who owes money and who should receive it
- Responsive and user-friendly interface

## 🌐 Live Demo

🔗 https://split-money-friends.vercel.app/

## 🛠️ Built With

- React
- TypeScript
- Vite
- CSS Modules
- React Hooks (`useState`)
